# epub-journey

After seeing KOReader, I'm curious about how an EPUB reader works, and I want to build one, but I don't know how. I have no experience with low-level file and byte reading, so I'm figuring it out from scratch (with JS too as it's the most familiar language for me).

This repo is a record of what I learn along the way and act as my own checkpoint when I switch device. Commits and files are messy.

**On AI:** I write all the code by hand on purpose. I use AI to explain concepts, sanity check my thinking, and teach me things I didn't know existed (like Little-Endian, or that Node has `readUInt16LE`).

Pls don't expect a polished product or a documented note. You're welcome to read, learn alongside me, or watch me struggle.
